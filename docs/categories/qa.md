# QA

The QA category holds checking tools: nodes that measure a result instead of changing it. Drop them at the end of a retouch chain to see how much an edit moved the image, or to compare two pipelines on the same input.

- [**N-44 QA Image Diff**](../nodes/qa-image-diff.md) — Compares two images with SSIM, PSNR and MAE and renders a heatmap, absolute or SSIM-map diff.

Related: [N-43 Mask Preview Overlay](../nodes/mask-preview.md) for checking masks visually.
